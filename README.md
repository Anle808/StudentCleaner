# StudentCleaner
Phần mềm dọn dẹp PC (Open Source)

## 📖 Giới thiệu (Vietnamese)
StudentCleaner là ứng dụng nhỏ gọn giúp dọn dẹp các file rác trên máy tính Windows.  
Ứng dụng được viết bằng Python và đóng gói thành file `.exe` để chạy trực tiếp.  
Dự án này là mã nguồn mở, bạn có thể tải về, chỉnh sửa, và chia sẻ.

## 📖 Introduction (English)
StudentCleaner is a lightweight application for cleaning junk files on Windows PCs.  
It is written in Python and packaged as a standalone `.exe` file.  
This project is open source, so you are free to download, modify, and share it.

---

## ⚙️ Cài đặt (Vietnamese)
- Tải file installer từ mục **Releases** trên GitHub.  
- Chạy `StudentCleanerSetup.exe` để cài đặt.  
- Shortcut sẽ xuất hiện trên Desktop và Start Menu.

## ⚙️ Installation (English)
- Download the installer from the **Releases** section on GitHub.  
- Run `StudentCleanerSetup.exe` to install.  
- A shortcut will be created on the Desktop and Start Menu.

---

## 💻 Sử dụng (Vietnamese)
- Mở StudentCleaner từ Desktop hoặc Start Menu.  
- Chọn chức năng dọn dẹp để xóa file rác.  
- Giao diện đơn giản, dễ sử dụng.

## 💻 Usage (English)
- Launch StudentCleaner from the Desktop or Start Menu.  
- Select the cleaning function to remove junk files.  
- Simple and user-friendly interface.
